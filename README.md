# 🎀 Outubro Rosa

Landing page responsiva desenvolvida para uma campanha de **conscientização sobre o Outubro Rosa**, com foco em informação, prevenção, cuidados e incentivo à procura de orientação profissional.

## 📌 Sobre o projecto

O **Outubro Rosa** é uma página web educativa criada para apresentar informações de forma simples, moderna e acessível.

A página foi desenvolvida com tecnologias web fundamentais, sem utilização de frameworks.

### Objectivos

- Divulgar informações sobre o Outubro Rosa;
- Incentivar a conscientização sobre a saúde da mama;
- Apresentar sinais e alterações que merecem atenção;
- Reforçar a importância do acompanhamento profissional;
- Criar uma experiência web moderna e responsiva;
- Demonstrar conhecimentos de desenvolvimento Front-End.

## 📂 Estrutura do projecto

```text
outubro-rosa/
│
├── index.html
├── style.css
├── script.js
└── README.md
```

### `index.html`

Contém a estrutura principal da landing page:

- Header;
- Menu de navegação;
- Hero;
- Sobre o Outubro Rosa;
- Sinais e alterações;
- Prevenção;
- Mensagem de conscientização;
- Secção de apoio;
- Footer.

### `style.css`

Responsável pelo aspecto visual da aplicação:

- Cores;
- Tipografia;
- Layout;
- Cards;
- Botões;
- Espaçamentos;
- Efeitos de hover;
- Responsividade;
- Menu mobile.

### `script.js`

Responsável pelas funcionalidades JavaScript:

- Abertura e fecho do menu mobile;
- Fecho automático do menu ao seleccionar uma opção;
- Actualização automática do ano no footer.

---

## 📱 Responsividade

A landing page foi preparada para funcionar em diferentes tamanhos de ecrã:

- 📱 Smartphones;
- 📲 Tablets;
- 💻 Computadores;
- 🖥️ Ecrãs maiores.

O layout adapta-se automaticamente através de **CSS Media Queries**.

## 🎨 Secções da página

### 1. Hero

Apresenta a mensagem principal da campanha:

> Prevenir é um acto de amor e cuidado.

Inclui botões para navegar para outras partes da página.

### 2. Sobre

Explica brevemente o propósito do Outubro Rosa e apresenta três áreas:

- Conscientização;
- Atenção aos sinais;
- Apoio.

### 3. Sinais

Apresenta exemplos de alterações que podem justificar uma avaliação profissional.

### 4. Prevenção

Apresenta recomendações gerais relacionadas com:

- Conhecimento do próprio corpo;
- Acompanhamento profissional;
- Hábitos saudáveis;
- Atenção a alterações.

### 5. Mensagem

Secção de destaque com uma mensagem de apoio e conscientização.

### 6. Apoio

Incentiva a procura de profissionais de saúde ou unidades sanitárias quando existir alguma preocupação.
